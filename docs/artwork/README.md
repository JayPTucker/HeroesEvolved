# The Unfinished Hour artwork

Original artwork generated for Heroes Evolved using the built-in imagegen tool on October 26, 2026. The revised outcome was edited from the original image using the same tool. Full-resolution sources live beside this file; only the two 16,384-byte vanilla-map palette assets ship in the mod. `tools/PreparePropheticArt.java` performs area sampling and palette conversion during asset preparation. The server reads the prepared bytes without image processing or a graphics dependency.

## Original prompt

Use case: illustration-story. Asset type: original square prophetic painting for a Minecraft superhero mod, usable as a low-resolution in-game map canvas. Create ONE square image, edge-to-edge painted scene, NO letters, NO words, NO border, NO UI. A haunted, handmade oil-and-charcoal painting of a dark research annex viewed from a slightly elevated entrance. Strong simple silhouettes and bold painterly blocks of color that remain readable at 128x128 pixels. Two barred glass holding cells stand symmetrically at the back left and back right, each containing one small human silhouette. Between them toward the foreground stands a copper reactor shaped like a glowing elongated heart/hourglass, radiating dangerous vivid orange heat. A single yellow guide stripe runs along the floor from the entrance toward the reactor, splitting around it. Grey-black stone architecture, copper pipes and cold turquoise observation glass; a large broken clock floats ominously above the scene at top center. Orange radiating light and charcoal cracks suggest a coming disaster. Palette midnight navy, desaturated teal, ochre, copper orange, parchment highlights. Elegant brush strokes, unsettling prophetic atmosphere, hand-painted by someone in a trance, not a diagram. Avoid tiny detail, photorealism, modern photographic props, gore, game screenshots, logos, text. Compose the scene with clear spatial relationships, cells and people visible, and a generous dominant orange reactor glow.

## Revised-outcome prompt

Edit this prophetic painting into its prevented-disaster outcome. Preserve the same square composition, exact architecture, the copper hourglass reactor, twin glass cells, overhead broken clock, painted oil/charcoal texture, and yellow floor guide. Extinguish the fires and orange wall cracks. The reactor is now safely glowing soft turquoise blue instead of blazing orange. Both holding cells are empty with open gates. The two small survivor silhouettes have escaped the cells and are now together on the yellow pathway near the bottom foreground, heading toward the viewer and safety. Give the scene a quiet, hopeful dawn reflected in the turquoise glass while keeping the dark haunted mood and ochre copper palette. No words, no logos, no UI, no added frame. This is the matching 'future revised' painting for the very same location.
